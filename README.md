# INSOS PrA Map

Interactive map of PrA (Praktische Ausbildung) training providers across Switzerland. Built on data from the [INSOS](https://www.insos.ch) member directory.

## Features

- Clustered marker map of ~365 PrA training providers on Swiss OSM tiles
- Hierarchical filtering by Bereich (sector) and Beruf (profession)
- Context-aware popups showing offered professions based on active filter
- Shareable URLs with filter and map position state via URL hash
- Static site — no backend required at runtime

## Prerequisites

- Node.js >= 18
- An `.env` file with OData credentials (for data refresh only)

## Getting Started

```bash
npm install

# Build provider data (fetches OData + geocodes; falls back to seed data)
npm run build:data

# Start dev server
npm run dev

# Production build
npm run build

# Full rebuild (data + frontend)
npm run build:all
```

## Project Structure

```
src/              Frontend (Vite + Leaflet + Tailwind)
  index.html        Shell with title bar, map container, footer
  main.js           Entry point — init map, filters, hash state
  map.js            Leaflet map, marker clustering, popup rendering
  filters.js        Sector/profession filtering logic and filter control
  hash-state.js     URL hash read/write for shareable links
  style.css         Layout, popup, and control styles
  public/data/      Static provider JSON (generated by build:data)

scripts/          Build-time data pipeline
  build-data.js     OData fetch → normalize → geocode → JSON

server/           Data pipeline modules
  odata-client.js   OData API client
  normalizer.js     Provider data normalization
  geocoder.js       Address geocoding with SQLite cache
```
