<task type="auto">
  <name>Task 1: Create Leaflet map module with SOSM tiles and marker clustering</name>
  <files>package.json, src/map.js</files>
  <action>
1. Install leaflet.markercluster:
   ```
   npm install leaflet.markercluster
   ```

2. Create `src/map.js` with the following structure:
   - Import Leaflet, then leaflet.markercluster as a side-effect (import order matters — markercluster attaches to global `L`)
   - Import all required CSS: `leaflet/dist/leaflet.css`, `leaflet.markercluster/dist/MarkerCluster.css`, `leaflet.markercluster/dist/MarkerCluster.Default.css`
   - Fix Leaflet default marker icons for Vite: import `marker-icon.png`, `marker-icon-2x.png`, `marker-shadow.png` from `leaflet/dist/images/` and override `L.Icon.Default.prototype.options` (iconUrl, iconRetinaUrl, shadowUrl) + set `L.Icon.Default.imagePath = ''`
   - Define Switzerland bounds constant: SW `[45.7, 5.9]`, NE `[47.9, 10.6]` (covers all 365 providers with padding)
   - Export `initMap(containerId, providers)` function that:
     a. Creates `L.map(containerId)` with `maxBounds: swissBounds.pad(0.1)`, `minZoom: 7`, `maxZoom: 18`
     b. Calls `map.fitBounds(swissBounds)` for initial view
     c. Adds SOSM Swiss-style tile layer: URL `https://tile.osm.ch/osm-swiss-style/{z}/{x}/{y}.png`, maxZoom 19, attribution `© OpenStreetMap`
     d. Creates `L.markerClusterGroup({ maxClusterRadius: 50, spiderfyOnMaxZoom: true, showCoverageOnHover: false, chunkedLoading: true })`
     e. Iterates over `providers` array, creates `L.marker([provider.lat, provider.lon])` for each provider with non-null coordinates, binds a minimal popup showing `provider.name` (just the name — full detail popups are Phase 3 scope)
     f. Adds all markers to the cluster group, adds cluster group to map
     g. Returns `{ map, clusters }` for potential future use
   - Use the exact code patterns from 02-RESEARCH.md (Pattern 1 through Pattern 4). The research has verified these patterns work with Leaflet 1.9.4 + Vite.
  </action>
  <verify>
Run `npm ls leaflet.markercluster` — should show 1.5.3 installed.
Run `node -e "import('leaflet')"` — should not error (leaflet importable).
Check `src/map.js` exports `initMap` function.
  </verify>
  <done>
`src/map.js` exists, exports `initMap(containerId, providers)`, imports Leaflet + markercluster with all CSS, fixes Vite marker icons, creates a bounded Swiss map with SOSM tiles and clustered markers.
  </done>
